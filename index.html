Consulta de IP público

Aviso de privacidade

Ao consultar, seu IP público será solicitado à API ipify. O serviço externo poderá processar essa informação. O histórico desta versão fica somente neste navegador.

Histórico local

O IP identifica a conexão à internet e não revela necessariamente seu endereço residencial exato.

📚 Aprende sobre endereços IP

🌐 O que é um IP?

Um endereço IP permite que dispositivos comuniquem através de uma rede. O IP público está associado à ligação que utilizas para aceder à internet.

🔎 O que um IP pode revelar?

Pode fornecer uma localização aproximada e informações sobre o fornecedor de internet. Não revela automaticamente o endereço exato da tua casa.

🛡️ Como proteger a tua privacidade

  • Não publiques o teu IP em locais públicos.
  • Evita links suspeitos.
  • Não partilhes dados pessoais com desconhecidos.
  • Verifica como os sites utilizam os teus dados.

💜 A consulta do IP deve ser transparente e autorizada. O histórico local fica guardado apenas neste navegador.
