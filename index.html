👑 Aulas VIP avançadas

DOM com JavaScript

O DOM permite selecionar e alterar elementos da página.

document.querySelector("h1").textContent = "Olá!";

CSS Flexbox

Organize itens em linhas ou colunas.

.container {
 display: flex;
 justify-content: center;
 align-items: center;
 gap: 12px;
}

Funções JavaScript

Funções guardam instruções que podem ser reutilizadas.

function saudacao(nome) {
 return "Olá, " + nome;
}

CSS Grid

Crie layouts com linhas e colunas.

.grade {
 display: grid;
 grid-template-columns: repeat(2, 1fr);
 gap: 12px;
}
