📚 Aprende sobre endereços IP

Descobre como os dispositivos comunicam pela internet e como proteger a tua privacidade.

🌐 O que é um IP?

Um endereço IP é utilizado para encaminhar informações entre dispositivos numa rede. O IP público está associado à ligação que utilizas para aceder à internet.

🔎 O que um IP pode revelar?

Pode indicar uma localização aproximada e informações sobre o fornecedor de internet. Não revela automaticamente o endereço exato da tua casa nem a identidade de uma pessoa.

🛡️ Como proteger a tua privacidade

  • Evita publicar o teu IP em espaços públicos.
  • Não abras links suspeitos.
  • Não partilhes dados pessoais com desconhecidos.
  • Lê os avisos de privacidade dos sites.
  • Mantém os teus dispositivos e aplicações atualizados.

🔐 IP público e IP privado

O IP público está associado à ligação à internet. O IP privado é utilizado para comunicar dentro de uma rede local, como o Wi-Fi de casa.

💜 Consulta apenas o teu IP ou informações que tens autorização para consultar.

Um IP identifica uma ligação de rede e não revela necessariamente o endereço residencial exato.
